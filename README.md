# Skyyards Bareilly 🏡

> **Skyyards Bareilly** - Complete real estate portal clone customized for Bareilly, Uttar Pradesh, featuring premium projects, verified duplex villas, BDA approved plots, locality trends, and live property insights.

---

- **Bareilly-Focused Real Estate**:
  - Highlights top Bareilly developments: *Kings Crest Luxury Duplex Villas*, *Olive Greens Township*, *Eldeco City*, *JHM Joy*, *JHM Desire*, and more.
- **5 Prime Bareilly Localities**:
  - **Dohra Road**: Airport corridor, 4-lane avenue, luxury villas & institutional hub.

  - **Pilibhit Bypass**: 6-lane express transit, Phoenix United Mall, integrated megatownships.
  - **Rampur Garden**: Prestigious doctor's hub, central location, boutique mansions & clinics.

- **Clean UI & Architecture**:
  - High-resolution, photorealistic architectural imagery for Bareilly localities and projects.
  - Responsive SVG price trend and asking price widgets with zero text collision.
  - Filterable property showcases with configuration, pricing, and BDA/RERA status.
  - Clean header with direct contact (**📞 08534026777**) and Schedule Visit CTA.
  - Zero clutter: all app download banners, sticky QR codes, and login popups removed.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Run Locally
```bash
# Clone the repository
git clone https://github.com/devwithwedivit-blip/skyyardnewweb.git

# Navigate into the project directory
cd skyyardnewweb

# Start the static HTTP server
node server.js
```

Open your browser and navigate to:
```
http://localhost:8080/
```

## 📁 Project Structure

- `index.html` - Main landing page with Bareilly hero search, hot selling projects, price insights, top localities, and property discovery.
